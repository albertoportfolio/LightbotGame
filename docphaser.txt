================================================================================
  1. ARQUITECTURA GENERAL
================================================================================

El juego usa dos runtimes separados (React y Phaser) conectados mediante un
EventEmitter compartido almacenado en el registry de Phaser.

Flujo de comunicación:

  React → Phaser:
    - run-commands      (ejecutar cola de comandos)
    - reset-level       (reiniciar nivel actual)
    - load-level        (cargar un nivel específico)
    - set-mute          (silenciar/activar audio)
    - set-volume        (ajustar volumen)
    - start-music       (iniciar música de fondo)
    - stop-music        (detener música de fondo)

  Phaser → React:
    - level-loaded      (nivel cargado con restricciones)
    - robot-moved       (robot se movió)
    - command-executed  (comando ejecutado)
    - command-failed    (comando falló)
    - level-complete    (nivel completado)

  3. TIPOS Y DEFINICIONES (src/types/game.types.ts - 77 líneas)
================================================================================

Tipos de Celda (CellType):
  'floor'     - Suelo transitable
  'empty'     - Espacio vacío (no transitable)
  'light'     - Luz que puede encenderse/apagarse
  'wall'      - Muro (no transitable)
  'plant'     - Planta (objetivo de llegada)
  'variable'  - Variable de color manipulable

Colores de Variable (VarColor):
  'red' | 'blue' | 'purple' | 'none'

Celda (Cell):
  {
    type: CellType        - Tipo de celda
    lit: boolean          - Si la luz está encendida (solo para 'light')
    varColor?: VarColor   - Color de variable (solo para 'variable')
  }

Direcciones (Direction):
  'UP' | 'RIGHT' | 'DOWN' | 'LEFT'

Comandos (Command - Enum):
  MOVE_FORWARD      - Avanzar una celda en la dirección actual
  TURN_LEFT         - Girar 90° a la izquierda
  TURN_RIGHT        - Girar 90° a la derecha
  LIGHT_TOGGLE      - Encender/apagar luz en la celda actual
  LOOP_UNTIL_PLANT  - Repetir comandos hasta llegar a planta
  COPY_VAR          - Copiar color de variable

Estado del Robot (RobotState):
  {
    row: number           - Fila actual en la cuadrícula
    col: number           - Columna actual en la cuadrícula
    direction: Direction  - Dirección a la que mira
  }

Definición de Nivel (LevelDef):
  {
    id: number                               - ID único (1-40)
    name: string                             - Nombre del nivel (español)
    robotStart: RobotState                   - Posición inicial del robot
    grid: CellType[][]                       - Mapa del nivel
    maxCommands: number                      - Límite de comandos
    maxAttempts: number                      - Intentos máximos
    instructions?: string                    - Pista del nivel
    allowedCommands?: Command[]              - Comandos permitidos
    textMode?: boolean                       - Habilitar entrada por texto
    varColors?: Record<"r,c", VarColor>      - Colores iniciales de variables
    victoryColors?: Record<"r,c", VarColor>  - Colores objetivo para ganar
  }

Estado de Nivel en Ejecución (LevelState):
  {
    grid: Cell[][]          - Cuadrícula mutable en tiempo real
    robot: RobotState       - Posición actual del robot
    isComplete: boolean     - Flag de victoria
  }

Eventos del Juego (GameEvents):
  Interfaz TypeScript que define los 7 tipos de eventos del EventEmitter.

================================================================================
  4. PUENTE REACT-PHASER (src/hooks/useGameBridge.ts - 101 líneas)
================================================================================

Hook de React que proporciona comunicación bidireccional con Phaser.

Implementación:
  - Usa useRef para mantener una instancia estable del emitter entre renders
  - Crea un Phaser.Events.EventEmitter de forma lazy en la primera llamada
  - Todos los callbacks devuelven funciones de desuscripción
  - El emitter se almacena en el registry de Phaser para acceso entre escenas

API de Emisión (React → Phaser):

  runCommands(commands: Command[])
    Envía la cola de comandos al ejecutor de Phaser.

  resetLevel()
    Reinicia el nivel actual al estado inicial.

  loadLevel(index: number)
    Carga un nivel específico por índice (0-39).

  setMute(muted: boolean)
    Activa o desactiva el silencio.

  setVolume(v: number)
    Ajusta el volumen maestro (0.0 - 1.0).

  stopMusic()
    Detiene la música de fondo.

  startMusic()
    Inicia la música de fondo.

API de Escucha (Phaser → React):

  onLevelComplete((data) => {...})
    Se dispara cuando el jugador completa el nivel.

  onCommandExecuted((data) => {...})
    Se dispara cuando un comando individual termina.

  onLevelLoaded((data) => {...})
    Se dispara cuando un nivel se carga con sus restricciones.

        * Frente: dos ojos grandes con brillo cian
        * Atrás: marca sutil oscura (sin ojos visibles)

  8. ESCENA PRINCIPAL (src/game/scenes/GameScene.ts - 522 líneas)
================================================================================

Propósito: Bucle principal del juego, renderizado, gestión de estado y
           condiciones de victoria.

--- Campos Privados ---

  bridge: Phaser.Events.EventEmitter   - Comunicación con React
  levelManager: LevelManager           - Catálogo de niveles
  levelState: LevelState               - Estado actual de cuadrícula + robot
  robot: Robot                         - Entidad robot
  executor: CommandExecutor            - Ejecutor de comandos
  bgGraphics: Phaser.GameObjects.Graphics      - Capa de fondo
  decorGraphics: Phaser.GameObjects.Graphics   - Capa de decoraciones
  gridGraphics: Phaser.GameObjects.Graphics    - Capa de cuadrícula
  wonThisLevel: boolean                - Flag de victoria
  sfx: SoundManager                    - Sistema de audio
  varLetterLabels: Text[]              - Etiquetas de letras de variables
  varValueLabels: Text[]               - Etiquetas de color de variables

--- Métodos del Ciclo de Vida ---

  create():
    1. Recupera el bridge del registry
    2. Crea objetos Graphics
    3. Inicializa CommandExecutor
    4. Dibuja el fondo
    5. Carga el nivel 0
    6. Registra listeners de eventos

  shutdown():
    1. Desregistra todos los event listeners
    2. Destruye el sprite del robot
    3. Detiene la música

--- Métodos de Renderizado ---

  drawBackground():
    - Gradiente de cielo (púrpura oscuro → azul → negro)
    - Campo de estrellas (60 estrellas blancas, opacidad variable)
    - Luna (color crema con sombras de cráteres)
    - Colinas (elipses púrpura oscuro, en capas)
    - Césped (rectángulo verde con patrón de dientes)
    - Nubes decorativas (5 círculos superpuestos)

  drawDecorations():
    - 4 árboles pixel-art en los bordes
    - 5 flores (rosa, amarilla, verde, roja, púrpura) con tallos

  drawTree(gfx, x, y):
    - Tronco marrón (2 rectángulos con offset)
    - 3 capas de triángulo (verde oscuro → medio → claro)
    - Círculo de reflejo

  renderGrid():
    Limpia y redibuja toda la cuadrícula. Renderizado por tipo de celda:

    wall (muro):
      Rectángulo redondeado gris con efecto 3D (borde, reflejo, sombra)

    plant (planta):
      Base marrón con decal de planta verde (tallo + 3 hojas en maceta)

    variable:
      Rectángulo redondeado coloreado (rojo/azul/púrpura/gris) con
      borde brillante

    light (luz):
      - Encendida: brillo cian, centro de estrella blanca, 8 rayos radiales
      - Apagada: púrpura oscuro con estrella sutil

    floor (suelo):
      Verde con textura de césped (círculos, sin borde de reflejo)

    Llama updateVarLabels() al final.

  drawVarLabels():
    Crea objetos de texto para cada celda 'variable':
    - Etiquetas de letras: A, B, C... (fijas, texto blanco, trazo negro)
    - Etiquetas de color: emoji (🔴 rojo, 🔵 azul, ⬜ ninguno)

  updateVarLabels():
    Actualiza el texto emoji según los valores actuales de varColor.

--- Gestión de Niveles ---

  loadLevel(index):
    1. Resetea flag de victoria
    2. Carga definición del nivel vía LevelManager
    3. Construye estado mutable
    4. Destruye robot antiguo, crea nuevo en posición inicial
    5. Renderiza cuadrícula y etiquetas de variables
    6. Reproduce jingle de inicio
    7. Inicia música de fondo (si no está silenciado)
    8. Emite 'level-loaded' con restricciones

--- Ejecución de Comandos ---

  handleRunCommands(commands):
    1. Previene ejecuciones simultáneas
    2. Pasa callback al CommandExecutor
    3. El callback aplica cada comando vía applyCommand()
    4. Re-renderiza la cuadrícula después de cada comando
    5. Verificaciones de victoria:
       a. Robot en celda 'plant' → victoria inmediata
       b. Variables coinciden con victoryColors → victoria
       c. Todas las luces encendidas → victoria
    6. Emite eventos 'robot-moved' y 'level-complete'
    7. Reproduce SFX apropiados

  applyCommand(cmd):
    MOVE_FORWARD  → robot.moveForward(); SFX move/error
    TURN_LEFT     → robot.turnLeft(); SFX turn
    TURN_RIGHT    → robot.turnRight(); SFX turn
    LIGHT_TOGGLE  → robot.toggleLight(); SFX lightOn/lightOff
    COPY_VAR      → robot.copyVar(); SFX lightOn/error
    Retorna boolean de éxito.

--- Lógica de Victoria ---

  Orden de prioridad:
    1. Si robot está en celda 'plant' → victoria inmediata
    2. Si hay variables Y los colores coinciden con victoryColors → victoria
    3. Si hay luces Y todas encendidas → victoria
    4. En otro caso → continúa ejecución

--- Manejadores de Eventos ---

  handleReset():    Detiene executor, recarga nivel actual
  handleLoadLevel(): Detiene executor, carga nuevo nivel
  handleSetMute():  Alterna estado de silencio

  9. ENTIDAD ROBOT (src/game/entities/Robot.ts - 148 líneas)
================================================================================

Propósito: Robot con mecánicas de movimiento, rotación y acciones.

--- Estado Interno ---

  sprite: Phaser.GameObjects.Sprite   - Representación visual
  state: RobotState                    - Posición y dirección actual
  lastVarCell: {row, col} | null       - Última variable visitada (para COPY_VAR)

--- Sistema de Direcciones ---

  DIRECTION_DELTAS:
    UP:    { dRow: -1, dCol:  0 }
    DOWN:  { dRow:  1, dCol:  0 }
    LEFT:  { dRow:  0, dCol: -1 }
    RIGHT: { dRow:  0, dCol:  1 }

  DIRECTION_ORDER: ['UP', 'RIGHT', 'DOWN', 'LEFT']
    Usado para calcular rotaciones (índice circular)

  DIRECTION_FRAME:
    DOWN: 0, UP: 1, RIGHT: 2, LEFT: 3
    Mapeo a frames del spritesheet

--- Métodos Principales ---

  moveForward(levelState) → boolean
    1. Calcula nueva posición: newRow = row + dRow, newCol = col + dCol
    2. Verificación de límites: si fuera del grid → false
    3. Verificación de celda:
       - Si 'empty' → false
       - Si 'wall' → false
    4. Si válido:
       - Actualiza state.row/col
       - Programa animación vía tween de Phaser (280ms, ease cúbico)
       - Retorna true

  turnLeft() → boolean
    idx = DIRECTION_ORDER.indexOf(actual)
    siguiente = DIRECTION_ORDER[(idx + 3) % 4]   // -1 mod 4
    Actualiza frame del sprite. Siempre retorna true.

  turnRight() → boolean
    idx = DIRECTION_ORDER.indexOf(actual)
    siguiente = DIRECTION_ORDER[(idx + 1) % 4]
    Actualiza frame del sprite. Siempre retorna true.

  toggleLight(levelState) → boolean
    Si la celda actual es 'light': alterna cell.lit → true/false
    Si no es 'light': retorna false

  copyVar(levelState) → boolean
    1. Verifica que la celda actual sea tipo 'variable' (sino → false)
    2. Primera visita a cualquier variable:
       - Almacena {row, col} como lastVarCell
       - Retorna true
    3. Visitas posteriores:
       - Si es la misma celda que lastVarCell → false
       - Copia varColor de celda actual → varColor de lastVarCell
       - Actualiza lastVarCell al punto actual
       - Retorna true

  animateTo(row, col) → void
    Tween de movimiento de Phaser con ease cúbico, duración 280ms.

  reset(initialState) → void
    Restaura estado inicial, limpia lastVarCell.

  destroy() → void
    Limpia el sprite.

  10. EJECUTOR DE COMANDOS (src/game/logic/CommandExecutor.ts - 96 líneas)
================================================================================

Propósito: Ejecución secuencial de comandos con soporte de bucles y límites
           de seguridad.

--- Estado Interno ---

  isRunning: boolean                    - Flag de estado de ejecución
  emitter: Phaser.Events.EventEmitter  - Para emitir eventos
  scene: Phaser.Scene                  - Referencia a la escena

--- Algoritmo Principal: execute(commands, callback) ---

  Máquina de estados:
    1. Establece isRunning = true
    2. Inicializa index = 0, loopCount = 0
    3. Entra en bucle runNext()

  Para cada comando:

    Si es LOOP_UNTIL_PLANT:
      ├─ Llama callback(LOOP_UNTIL_PLANT) → retorna true si está en planta
      ├─ Si true: SALE de la ejecución (bucle completado)
      ├─ Si false:
      │  ├─ Incrementa loopCount
      │  ├─ Si loopCount >= 20 (MAX_LOOP_ITERATIONS):
      │  │   └─ Emite error, detiene ejecución
      │  ├─ Resetea index = 0 (reinicia desde el principio)
      │  └─ Programa runNext() después de COMMAND_DELAY_MS
      │

    Si es comando normal:
      ├─ Llama callback(cmd) → ejecuta acción del robot
      ├─ Emite 'command-executed'
      ├─ Si callback retorna false:
      │  ├─ Emite 'command-failed'
      │  └─ Detiene ejecución
      ├─ Incrementa index
      └─ Programa runNext() después de COMMAND_DELAY_MS

--- Tiempos ---

  Retardo inicial: 100ms antes del primer comando
  Entre comandos: 380ms (COMMAND_DELAY_MS)
  Resultado: Animación de robot suave y visible

--- Seguridad ---

  MAX_LOOP_ITERATIONS = 20
  Si LOOP_UNTIL_PLANT se repite más de 20 veces, aborta la ejecución.
  Previene bucles infinitos.

--- Método stop() ---

  stop() { isRunning = false }
  Detiene la ejecución de forma elegante.

  12. PARSER DE TEXTO (src/game/logic/textCommandParser.ts - 46 líneas)
================================================================================

Propósito: Convertir comandos de texto en español a enum Command.

Función: parseTextCommands(input: string)

Formato de Entrada:
  "AVANZA 3, IZQUIERDA, LUZ"
  Los espacios separan comando de cantidad.
  Las comas separan comandos.

Aliases (español → enum):
  'AVANZA'     → MOVE_FORWARD
  'IZQUIERDA'  → TURN_LEFT
  'DERECHA'    → TURN_RIGHT
  'LUZ'        → LIGHT_TOGGLE
  'COPIAR'     → COPY_VAR
  'BUCLE'      → LOOP_UNTIL_PLANT

Algoritmo de Parsing:
  1. Divide por comas, recorta espacios
  2. Para cada token:
     - Extrae nombre del comando (primera palabra, mayúsculas)
     - Extrae cantidad de repeticiones (segunda palabra como entero, default 1)
     - Valida: repeticiones ∈ [1, 20]
     - Añade al array de salida 'cantidad' veces
  3. Valida: al menos un comando
  4. Retorna { commands, error: null } o { commands: [], error: "mensaje" }

Casos de Error:
  - Comando desconocido: "Comando desconocido: ..."
  - Cantidad inválida: "Número de pasos inválido..."
  - Entrada vacía: "Escribe al menos un comando"

  13. GESTOR DE NIVELES (src/game/levels/LevelManager.ts - 134 líneas)
================================================================================

Propósito: Catálogo de niveles y construcción de estado.

Datos Estáticos:

  LEVELS: LevelDef[] = [level1, ..., level40]   // 40 niveles en 4 mundos

  Mundos:
    1. Tierra de Luces     (niveles 0-9)   - Mecánicas básicas
    2. Islas del Código     (niveles 10-19) - Intermedio
    3. Galaxia Robot        (niveles 20-29) - Avanzado
    4. Volcán Digital       (niveles 30-39) - Experto

API:

  current → LevelDef
    Obtiene el nivel cargado actualmente.

  currentLevelIndex → number
    Obtiene el índice base-0.

  hasNext → boolean
    Verifica si existen más niveles.

  getLevelCount() → number
    Cantidad total de niveles (40).

  loadLevel(index) → LevelDef
    Carga nivel por índice; lanza error si está fuera de rango.

  loadNext() → LevelDef | null
    Avanza al siguiente; retorna null si está al final.

Construcción de Estado: buildState(def)

  Para cada celda en def.grid:
    ├─ Crea Cell mutable { type, lit: false, varColor? }
    ├─ Si la celda variable tiene varColor inicial en def.varColors:
    │  └─ Lo aplica (búsqueda por clave string "row,col")
    └─ En otro caso: varColor = 'none'

  Retorna LevelState { grid, robot: {...def.robotStart}, isComplete: false }

Verificación de Victoria: checkVictory(state, def)

  Detecta contenido de la cuadrícula:
    hasVar   = ¿hay celdas 'variable'?
    hasPlant = ¿hay celdas 'plant'?
    hasLights = ¿hay celdas 'light'?

  Condiciones de victoria (prioridad):
    1. Si hasVar: verifica si todas las variables coinciden con def.victoryColors
       └─ Victoria ← TODAS coinciden
    2. Si hasPlant: retorna false (victoria por planta se maneja en GameScene)
    3. Si hasLights: verifica si TODAS están encendidas (cell.lit === true)
       └─ Victoria ← TODAS encendidas
    4. Sino: retorna false

  14. SISTEMA DE AUDIO (src/game/audio/SoundManager.ts - 336 líneas)
================================================================================

Propósito: Síntesis de audio procedural usando Web Audio API.
           No se usan archivos de audio externos.

--- Control Maestro ---

  ctx: AudioContext              - Contexto Web Audio
  masterGain: GainNode           - Control de volumen maestro
  muted: boolean                 - Estado de silencio
  musicPlaying: boolean          - Flag de bucle de música
  _volume: number = 0.8          - Volumen maestro (0-1)

--- Métodos Primitivos ---

  playTone(freq, duration, type='square', vol, delay)
    Crea oscilador con envolvente de ataque/liberación.
    Tipos: 'square' | 'sine' | 'sawtooth'

  playNoise(duration, vol, delay)
    Genera ruido blanco con filtro pasa-banda.
    Usado para efectos de percusión.

  scheduleTone(freq, duration, type, vol, startTime)
    Programa tono para reproducirse en tiempo absoluto de Web Audio.
    Usado para secuenciación del bucle musical.

  scheduleNoise(duration, vol, startTime)
    Programa ruido en tiempo absoluto con filtro pasa-alto.

--- Sistema Musical ---

  startMusic()
    Inicia la pista de fondo en bucle.

  stopMusic()
    Detiene el bucle, fade out.

  playMusicLoop()
    Frase musical de 8 compases.

    Tempo: 120 BPM (pulso = 0.5s)
    Duración: ~6.4 segundos

    Capas paralelas:
      1. Melodía (onda cuadrada): rango 523-880 Hz
         - Frase de 2 compases repetida, 2 variaciones
         - Notas con duraciones variadas (completa, media, cuarto)

      2. Bajo (diente de sierra): rango 98-165 Hz
         - Notas staccato (patrón encendido-apagado)
         - Progresión de acordes

      3. Arpegio (onda triangular): armónico
         - Pulsos de semicorchea (8 por tiempo)
         - Dos patrones alternando cada 4 compases

      4. Percusión (ruido filtrado pasa-alto):
         - Kick: pulso de negra (tiempo)
         - Hi-hat: pulso de corchea (2x velocidad del kick)

    Auto-bucle: programa el siguiente ciclo 100ms antes de que termine.

--- Efectos de Sonido (SFX) ---

  move()
    Beep de dos tonos: 180Hz + 220Hz

  turn()
    Descenso de tono: 440Hz → 330Hz

  lightOn()
    Acorde ascendente: 660Hz → 880Hz

  lightOff()
    Acorde descendente: 440Hz → 330Hz

  error()
    Cluster de diente de sierra + ruido

  plantReached()
    Fanfarria ascendente de 5 notas

  loopTick()
    Pulso corto de onda cuadrada

  levelComplete()
    Progresión de acordes sobre la música

  levelStart()
    Jingle de inicio de 3 notas

  buttonClick()
    Tono único de seno

--- Control de Volumen ---

  setVolume(v: number)
    Ajuste de volumen en tiempo real vía setTargetAtTime.

  toggleMute()
    Fade suave a/desde 0, reanuda música al quitar silencio.

--- Algoritmos Clave ---

  Envolvente Ataque/Liberación:
    linearRampToValueAtTime + exponentialRampToValueAtTime

  Programación:
    Usa Web Audio currentTime para programación precisa.

  Filtrado:
    Filtros Biquad para pasa-banda (ruido) y pasa-alto (hi-hat).

================================================================================
  16. FLUJO DE DATOS COMPLETO
================================================================================

--- Diagrama de Flujo ---

  Componente React
      ↓
  useGameBridge (EventEmitter)
      ↓
  GameScene (recibe eventos vía bridge)
      ├─ LevelManager (carga definiciones de nivel)
      ├─ Robot (entidad con estado)
      ├─ CommandExecutor (procesa comandos)
      ├─ SoundManager (síntesis de audio)
      └─ renderGrid() → emite 'robot-moved'
      ↓
  React recibe eventos, actualiza UI

--- Bucle de Juego ---

  1. Jugador pulsa "Ejecutar" → React emite 'run-commands' vía bridge
  2. GameScene recibe evento → pasa al CommandExecutor
  3. Bucle del CommandExecutor:
     a. Obtiene siguiente comando
     b. Llama callback de GameScene para aplicar comando
     c. Callback actualiza estado del robot/cuadrícula
     d. GameScene re-renderiza cuadrícula
     e. Verifica condiciones de victoria
     f. Emite 'robot-moved' de vuelta a React
     g. Espera COMMAND_DELAY_MS (380ms)
  4. En victoria: emite 'level-complete'
  5. React actualiza la UI

================================================================================
  17. ALGORITMOS CLAVE
================================================================================

--- Movimiento del Robot (Robot.moveForward) ---

  Entrada: LevelState (referencia a la cuadrícula)
  Salida: boolean (éxito)

  1. Calcular nueva posición: newRow = row + dRow, newCol = col + dCol
  2. Verificar límites: si newRow/newCol fuera del grid → false
  3. Verificar tipo de celda:
     - Si 'empty' → false
     - Si 'wall' → false
  4. Si válido:
     - Actualizar this.state.row/col
     - Programar animación vía tween de Phaser
     - Retornar true

--- Copia de Color de Variable (Robot.copyVar) ---

  La celda actual debe ser tipo 'variable' (sino → false)

  Primera visita a cualquier variable:
    - Almacenar {row, col} como lastVarCell
    - Retornar true (primera visita exitosa)

  Visitas posteriores:
    - Si es la misma celda que lastVarCell → false (sin copia)
    - Copiar varColor de celda actual → varColor de lastVarCell
    - Actualizar puntero lastVarCell a celda actual
    - Retornar true

--- Rotación de Dirección ---

  Dirección actual en DIRECTION_ORDER: ['UP', 'RIGHT', 'DOWN', 'LEFT']

  turnLeft:
    idx = indexOf(actual)
    siguiente = DIRECTION_ORDER[(idx + 3) % 4]  // -1 mod 4

  turnRight:
    idx = indexOf(actual)
    siguiente = DIRECTION_ORDER[(idx + 1) % 4]

--- Transformación Celda-a-Mundo ---

  cellToWorld(row, col):
    x = GRID_OFFSET_X + col * CELL_SIZE + CELL_SIZE/2
    y = GRID_OFFSET_Y + row * CELL_SIZE + CELL_SIZE/2

  Ejemplo: (fila=1, col=2) con OFFSET (24,24) y SIZE 64
    x = 24 + 2*64 + 32 = 184
    y = 24 + 1*64 + 32 = 120

--- Bucle Musical Web Audio ---

  Tempo: 120 BPM (pulso = 0.5s, compás = 2s)
  Duración: 8 compases (16s)

  Capas paralelas programadas vía Web Audio currentTime:
    1. Melodía: onda cuadrada, rango 523-880 Hz
    2. Bajo: diente de sierra, rango 98-165 Hz
    3. Arpegio: onda triangular, patrones alternos
    4. Percusión: ruido filtrado (kick + hi-hat)

  Auto-bucle: programa siguiente ciclo 100ms antes de terminar.

--- Jerarquía de Detección de Victoria ---

  Robot en celda planta
    ↓ SÍ → Victoria instantánea
    ↓ NO
  Variables coinciden con colores objetivo
    ↓ SÍ → Victoria
    ↓ NO
  Todas las luces encendidas
    ↓ SÍ → Victoria
    ↓ NO
  La ejecución continúa

--- Árbol de Ejecución de Comandos ---

  LOOP_UNTIL_PLANT
    ↓ ¿Robot en planta?
    ├─ SÍ → Salir del bucle, detener ejecución
    └─ NO
        ├─ Incrementar contador de bucle
        ├─ Si contador >= 20 → Error, detener
        └─ Resetear índice a 0, reiniciar

  Comando Normal (MOVE_FORWARD, TURN_*, LIGHT_TOGGLE, COPY_VAR)
    ↓ Ejecutar callback
    ├─ Retorna true → Éxito, continuar
    └─ Retorna false → Fallo, detener ejecución
